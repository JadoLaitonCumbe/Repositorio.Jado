GEmpresa-JLC — Business Management System (ERP)
Developer: JLC-tech
Version: 1.0.0
Status: Under development and continuous improvement.

GEmpresa-JLC is a software development project designed to integrate and simplify various business management processes within a single platform.

The system aims to provide tools for organizing business operations, including financial management, human resources, departments, customers, suppliers, products, inventory, and strategic planning.

Key Implemented Features:
- Central General Administration Dashboard.
- Company and branch registration and management.
- Employee, department, and permission management.
- Revenue, expenses, and financial transactions management.
- Customer and supplier management.
- Product registration and inventory control.
- Strategic planning and project tracking.
- Financial reports in PDF and Excel formats.
- Hybrid architecture with a Web application and Desktop client.
- Synchronization of financial transactions between the Desktop client and server.
- Audit logging and device management.
Technologies Used:
- Python
- FastAPI
- SQLite
- HTML and CSS
- Jinja2
- PostgreSQL (migration structure prepared)
- Redis (integration for distributed request rate limiting)
- Git and GitHub
Project Objective:

To develop a modular, secure, and scalable business management platform with the potential to support companies of different sizes in Mozambique.

This project was developed as part of my practical learning journey and continuous growth in software development.
